# 🩺 مشروع المساعد الطبي الذكي القائم على الـ RAG (Medical RAG AI Assistant)

هذا الدليل يوضح هيكل المشروع، كيفية عمله خطوة بخطوة، وطرق إعداده وتشغيله بالكامل من الصفر بطريقة منظمة ونظيفة.

## 🗺️ أولاً: هيكل الملفات والمجلدات (Project Directory Structure)

تم تصميم المشروع بشكل مجزأ (Modular) لفصل المسؤوليات وتسهيل الصيانة والتطوير:

```text
rag-system/
│

├── requirements.txt           # مكتبات المشروع المطلوبة
├── .env                       # ملف الإعدادات ومفاتيح الـ APIs (Groq, Cohere, Qdrant)
├── app.py                     # الملف الرئيسي لتشغيل واجهة Streamlit
├── main.py                    # واجهة الـ CLI البديلة للاستعلام عبر الكونسول
│
├── data/                      # المجلد الخاص بالبيانات والملفات
│   ├── 9789241550284-eng.pdf  # كتاب إرشادات منظمة الصحة العالمية (الملف الأصلي)
│   ├── chunks/                # النصوص المجزأة بعد معالجتها وتقطيعها
│   └── embeddings/            # ملفات المتجهات الشعاعية (Embeddings)
│
├── scripts/                   # السكريبتات المساعدة للتشغيل السريع
│   ├── download_pdf.py        # لتحميل ملف الـ PDF الأصلي تلقائياً
│   ├── cleanup.py             # لتنظيف المجلدات والبدء من جديد
│   ├── reset_vector_db.py     # لمسح قاعدة بيانات المتجهات
│   └── ingest.py              # لتشغيل أنبوب البيانات بالكامل (Ingestion)
│
└── src/                       # الكود البرمجي الأساسي للنظام
    └── rag_system/
        ├── config/            # إعدادات النظام وقراءة البيئة (.env)
        ├── ingestion/         # أنبوب معالجة النص والإدخال لـ Qdrant
        ├── retriever/         # محرك البحث الشعاعي واسترجاع النصوص
        ├── llm/               # الاتصال بالنماذج اللغوية (Groq أو Ollama)
        ├── app.py             # الواجهة الرسومية لتطبيق Streamlit
        └── shared/            # أدوات مساعدة مشتركة
```

## ⚙️ ثانياً: معمارية النظام (System Architecture)

ينقسم النظام إلى مرحلتين أساسيتين:

### 1. خط معالجة البيانات وإدخالها (Ingestion Pipeline)
يقوم بتحويل مستند الـ PDF الخام إلى متجهات في قاعدة البيانات ويمر بالخطوات التالية:
1. **التحليل (Parsing):** قراءة الـ PDF عبر مكتبة `pdfplumber` واستخراج النصوص والجداول بدقة وتجنب تداخل الأعمدة.
2. **التنظيف (Cleaning):** تنظيف النصوص وإزالة الهوامش المتكررة وتصحيح انقسامات الكلمات.
3. **الهيكلة الهرمية (Hierarchy):** تصنيف المستند إلى فصول وأقسام للحفاظ على السياق.
4. **التقطيع الدلالي (Semantic Chunking):** تقطيع النص لقطع ذكية (300 - 600 رمز) بحيث لا ينفصل عنوان عن فقرته.
5. **توليد المتجهات (Embedding):** تحويل الكتل النصية لمتجهات شعاعية باستخدام Cohere API (أو نموذج محلي عبر Ollama).
6. **الفهرسة (Indexing):** حفظ المتجهات وتوثيق البيانات الوصفية (Metadata) داخل قاعدة بيانات **Qdrant**.

### 2. محرك البحث والاسترجاع المدعم بالتوليد (RAG Pipeline)
عند طرح سؤال من الطبيب:
1. **معالجة السؤال (Query Processing):** توسيع الاختصارات الطبية (مثل تحويل `t2d` إلى `type 2 diabetes`).
2. **البحث الشعاعي (Vector Search):** استخراج أقرب الفقرات شبهاً دلالياً بالسؤال من Qdrant.
3. **إعادة الترتيب (Reranking):** تصفية وترتيب الفقرات لضمان دقة النتائج.
4. **التوليد بالـ LLM (Generation):** صياغة الإجابة الطبية النهائية باستخدام نموذج لغوي مع ذكر المصدر ورقم الصفحة بدقة (مثل `[WHO Guidelines Page 12]`).

## 🚀 ثالثاً: دليل التشغيل خطوة بخطوة (Step-by-Step Setup Guide)

اتبع هذه الخطوات الست لبناء وتشغيل المشروع من الصفر:

### الخطوة 1: تثبيت المكتبات المطلوبة
قم بتثبيت الاعتماديات الخاصة بالمشروع:
```powershell
pip install -r requirements.txt
```

### الخطوة 2: تشغيل حاوية Qdrant (Docker)
تأكد من أن برنامج Docker Desktop يعمل في جهازك، ثم شغل حاوية Qdrant:
```powershell
docker compose up -d
```

### الخطوة 3: ضبط الإعدادات البيئية
قم بإنشاء ملف `.env` في المجلد الرئيسي وتأكد من كتابة المفاتيح المناسبة مثل مفتاح Groq ومفتاح Cohere وإعدادات Qdrant:
```env
QDRANT_HOST=localhost
QDRANT_PORT=6333
QDRANT_COLLECTION=who_guidelines
GROQ_API_KEY=your_groq_api_key
COHERE_API_KEY=your_cohere_api_key
```

### الخطوة 4: تنظيف البيئة وتحميل ملف الـ PDF
إذا كنت تريد بدء معالجة جديدة خالية من أي ملفات قديمة:
1. قم بتشغيل سكريبت التنظيف:
   ```powershell
   python scripts/cleanup.py
   ```
2. ضع ملف الـ PDF الطبي الأصلي داخل مجلد `data/` وتأكد من تسميته **`9789241550284-eng.pdf`**.
   *(أو يمكنك تشغيل سكريبت التحميل التلقائي: `python scripts/download_pdf.py`)*

### 5. تشغيل معالجة البيانات والرفع لقاعدة البيانات (Ingestion)
قم بمعالجة المستند وتقطيعه ورفعه لـ Qdrant:
```powershell
python scripts/ingest.py
```

### 6. تشغيل واجهة Streamlit الرسومية
قم بتشغيل واجهة المستخدم التفاعلية على المتصفح:
```powershell
streamlit run app.py
```
